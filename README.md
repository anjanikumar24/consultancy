# Bhumi Pathways Consultancy: Django website

Server-rendered Django site. **Frontend:** Django templates + HTML, CSS, JavaScript and Bootstrap 5. **Backend:** Python + Django only (no Django REST Framework). **Database:** SQLite (`db.sqlite3`) by default. **All page content is editable in the Django admin panel.**

Layout and structure are inspired by admissionshala.com (announcement bar, sticky nav, full-width hero with quick selector, card sections, call-to-action, link-rich footer). All text, colours, logo and design here are original.

## Quick start (Windows)
1. Install Python 3.11+ from python.org (tick "Add python.exe to PATH").
2. Open PowerShell in this folder and run `.\setup_windows.bat`. It creates a virtual environment, installs packages, creates the database tables, seeds starter content and asks you to create an admin login.
3. Start: `env\Scripts\activate` then `python manage.py runserver`
4. Website: http://127.0.0.1:8000/  Admin: http://127.0.0.1:8000/admin/

Manual equivalent (any OS):
```bash
python -m venv env && source env/bin/activate      # Windows: env\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                # Windows: copy .env.example .env
python manage.py makemigrations core
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
python manage.py test                               # 20+ tests, in-memory database
```

## What you can edit in the admin panel (`/admin/`)
| Admin section | Controls |
|---|---|
| **Site settings** | Site name, tagline, top announcement bar, main button label, phone, email, WhatsApp number and message, address, office hours, footer text, default Google description, enquiry alert emails, home page section headings |
| **Page content** | For each page (Home, About, Services, Destinations, Visa, FAQs, Contact, Privacy, Terms): Google title and description, main heading, text under heading, section heading/intro, main content (HTML allowed), notice box |
| **Menu links** | Top menu, footer "Explore" links, footer bottom links: add, rename, reorder, hide |
| **Study destinations** | Country cards: name, flag emoji, intro, intakes, key points (one per line), order, show/hide |
| **Services / Process steps / About page principles / Visa documents / FAQs** | Add, edit, reorder, hide items |
| **Enquiries** | View submissions, change status, add internal notes, filter, search, bulk-mark, export CSV |

Tip: in lists, edit **Order** and **Show on website** directly in the table and click Save. HTML in "Main content" is output as written, so only give admin access to trusted staff.

Not editable from admin (needs a developer): colours/fonts (`static/css/site.css`), page layout (templates), images (the design uses no photos).

## Email notifications
Configured with env vars in `.env` (see `.env.example`): `EMAIL_BACKEND`, `EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD`, `DEFAULT_FROM_EMAIL`, `ENQUIRY_NOTIFY_EMAILS` (or set "Notification emails" in Site settings), `ENQUIRY_SEND_ACKNOWLEDGEMENT`. In development emails print in the terminal. Email failures are logged and never lose the enquiry.

## Security notes
CSRF on all forms; honeypot field; per-IP rate limit (`ENQUIRY_RATE_LIMIT`, per hour, per server process); server-side validation; email-header injection stripped; CSV export neutralises spreadsheet formulas; production mode forces HTTPS, HSTS and secure cookies; secret key required in production; admin lives at `/admin/` (use a strong password; consider changing the URL in `config/urls.py`).

## SEO
Per-page title/description/canonical/Open Graph (editable), FAQ and organisation structured data, `/sitemap.xml`, `/robots.txt` (blocks `/admin/`), thank-you page is `noindex`. No `og:image` because no brand image exists yet.

# Deployment (Ubuntu VPS, Nginx + Gunicorn, SQLite)

SQLite is fine for a low-traffic enquiry site. It is one file, so back it up (see step 6).

```bash
# 1. Server
sudo apt update && sudo apt install -y python3-venv nginx certbot python3-certbot-nginx ufw
sudo ufw allow OpenSSH && sudo ufw allow 'Nginx Full' && sudo ufw enable
sudo adduser --system --group --home /srv/bhumi bhumi

# 2. Code: copy this folder to /srv/bhumi (git clone or scp/unzip)
cd /srv/bhumi
sudo -u bhumi python3 -m venv venv
sudo -u bhumi venv/bin/pip install -r requirements.txt

# 3. Environment
sudo -u bhumi cp .env.example .env && sudo -u bhumi nano .env
#   DJANGO_DEBUG=False, DJANGO_SECRET_KEY=<python3 -c "import secrets;print(secrets.token_urlsafe(60))">
#   DJANGO_ALLOWED_HOSTS=bhumipathwaysconsultancy.com,www.bhumipathwaysconsultancy.com
#   CSRF_TRUSTED_ORIGINS=https://bhumipathwaysconsultancy.com,https://www.bhumipathwaysconsultancy.com
#   BEHIND_PROXY=True, real SMTP settings, ENQUIRY_NOTIFY_EMAILS
sudo chmod 600 .env

# 4. Database + static files
sudo -u bhumi venv/bin/python manage.py makemigrations core   # skip if you committed migrations from your PC
sudo -u bhumi venv/bin/python manage.py migrate
sudo -u bhumi venv/bin/python manage.py collectstatic --noinput
sudo -u bhumi venv/bin/python manage.py createsuperuser

# 5. Services
sudo cp deploy/gunicorn.service /etc/systemd/system/bhumi.service
sudo systemctl daemon-reload && sudo systemctl enable --now bhumi
sudo cp deploy/nginx.conf /etc/nginx/sites-available/bhumi
sudo ln -s /etc/nginx/sites-available/bhumi /etc/nginx/sites-enabled/bhumi
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx

# 6. Nightly backup of the database file (cron: sudo crontab -e)
#   0 2 * * * sqlite3 /srv/bhumi/db.sqlite3 ".backup '/srv/backups/bhumi-$(date +\%F).sqlite3'"
```
Tip: if you build the database on your PC first, run `makemigrations core` there and copy the generated `core/migrations/0001_initial.py` to the server so both match.

## Connect the domain
At your registrar's DNS panel add: `A  @  → server IPv4` and `A  www → server IPv4` (or `CNAME www → bhumipathwaysconsultancy.com`). Check with `dig +short bhumipathwaysconsultancy.com`. Then:
```bash
sudo certbot --nginx -d bhumipathwaysconsultancy.com -d www.bhumipathwaysconsultancy.com
sudo certbot renew --dry-run
sudo systemctl restart bhumi
```

## Post-deploy checklist (do this before calling it live)
1. Every page loads over `https://`, including `/sitemap.xml` and `/robots.txt`.
2. Submit a real enquiry: it appears in Admin > Enquiries and the notification email arrives (check spam).
3. Edit a heading in Admin > Page content and confirm it changes on the live page.
4. Check on a real phone; the WhatsApp button opens the right chat.
5. Submit the sitemap in Google Search Console.
